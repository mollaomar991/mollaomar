First systematic study of prompt injection attacks in Bangla (pure, Banglish, mixed-script). Novel 2,972-prompt dataset across 11 attack categories; LoRA fine-tuning on a single RTX 3050.

03

Spatio-Temporal Air Pollution Spike Forecasting — Bangladesh

Hybrid framework — ST-DBSCAN clustering + Apriori association rules + gradient-boosted ensemble — to forecast hazardous PM2.5 spikes across 6 Bangladeshi cities from 208,368+ hourly records.

0.867 F1 Score (t+1h)
90.4% Recall
0.930 PR-AUC
  • XGBoost
  • LightGBM
  • ST-DBSCAN
  • Apriori
  • SMOTE
  • SHAP

Vision-Language Framework for Knee MRI Analysis

Two-stage pipeline — YOLOv11m object detection on 2.5D pseudo-RGB fastMRI slices + Qwen2.5-VL-3B report generation — for abnormality localisation and clinical question answering.

0.393 mAP@50 (best class)
5 Clinical super-classes
1,488 Validation slices
